# 📊 Sales Data Analytics Dashboard

An interactive Sales Data Analytics Dashboard built using Python, Pandas, Plotly and Streamlit to analyze Superstore sales data and discover valuable business insights.

## 🚀 Project Overview

This project analyzes sales records and presents business performance through interactive charts, KPI metrics and filters.

## ✨ Features

- Interactive sales dashboard
- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Average Order Value
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top 10 Best-Selling Products
- Sub-Category Sales Analysis
- Region and Category filters
- Date range filter
- Download filtered sales data
- Welcome screen

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd sales-data-analytics-dashboard
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the dashboard:

```bash
streamlit run app.py
```

## 📈 Project Objective

To transform raw sales data into meaningful visual insights and help users understand sales performance across products, categories, regions and time periods.
